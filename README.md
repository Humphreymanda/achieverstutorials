# achievers tutorials

Tutorial/learning platform for first-year students in the School of Mathematics and Natural Sciences at Copperbelt University.

## Status
🚧 Scaffolding — Supabase project created, Git initialized.

## Stack
- Vanilla HTML / CSS / JS (ES modules) — no build step
- Node.js + Express (`server.js`) with `/api` routes
- Supabase (Postgres + Auth + Storage)
- Deployed on Railway
